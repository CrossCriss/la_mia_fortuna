# Де взяти ключі для `.env`

Покрокова інструкція для кожного сервісу. Коли отримаєш значення — просто
вклей їх мені в чат (або сам допиши в `.env`), і я одразу підключу й перевірю.

## 1. Supabase — база даних + сховище фото

1. [supabase.com](https://supabase.com) → Sign up (картка не потрібна, безкоштовного тарифу вистачить на старт).
2. New Project: назва (напр. `la-mia-fortuna`), пароль для БД — **збережи його окремо**, регіон — `eu-central-1` (Frankfurt, найближчий до України).
3. Project Settings → Database → Connection string:
   - вкладка **Transaction** (порт 6543) → це `DATABASE_URL`
   - вкладка **Session** (порт 5432) → це `DIRECT_URL`
   - в обох підстав свій пароль замість `[YOUR-PASSWORD]`
4. Project Settings → API:
   - **Project URL** → `SUPABASE_URL`
   - **service_role key** (не `anon` — саме service_role) → `SUPABASE_SERVICE_ROLE_KEY`
5. Storage → New bucket → назва `product-images` → увімкнути **Public bucket** (інакше фото не відкриються на сайті).

## 2. Monobank Acquiring (Plata by mono) — оплата карткою

Для реального прийому платежів потрібен бізнес-акаунт Monobank на ФОП клієнтки.
Щоб перевірити інтеграцію ще до цього — є безкоштовний тестовий токен:

- **Тест (можна зараз, без ФОП):** [api.monobank.ua](https://api.monobank.ua/) → кнопка "Створити тестовий токен" → `MONOBANK_TOKEN`. Гроші не списуються по-справжньому, зручно перевірити весь ланцюжок (чекаут → оплата → вебхук → статус замовлення).
- **Бойовий (коли готові приймати гроші):** застосунок Monobank для бізнесу → Plata by mono / Еквайринг → підключити онлайн-еквайринг для сайту → особистий кабінет для бізнесу → API → токен.

## 3. Nova Poshta — автокомплит відділень

1. [my.novaposhta.ua](https://my.novaposhta.ua) → увійти/зареєструватись за номером телефону (звичайний клієнтський кабінет, навіть без договору на відправлення).
2. Налаштування → API → згенерувати ключ (безкоштовно, без заявки).
3. Це `NOVA_POSHTA_API_KEY`.

## 4. (опційно) LiqPay — якщо захочете замінити Monobank

Потрібен рахунок ФОП у Приватбанку → підключення LiqPay-еквайрингу в кабінеті
ПриватБанку → `liqpay.ua` → Кабінет → Public key / Private key →
`LIQPAY_PUBLIC_KEY` / `LIQPAY_PRIVATE_KEY`, і виставити `PAYMENT_PROVIDER="LIQPAY"`
замість `MONOBANK`.

---

Найшвидший шлях перевірити все вже зараз: Supabase (5 хв, безкоштовно) +
Monobank тестовий токен (1 хв) + Nova Poshta ключ (2 хв) — жоден не потребує
реальних грошей чи документів ФОП.
