# E-commerce Starter Template

Готовий каркас інтернет-магазину для швидкого старту нових клієнтських проектів (інста-шопи, невеликі бренди). Витягнутий з реального проекту після першого повного циклу розробки — тут уже вирішені типові архітектурні питання, тож новий магазин починається не з нуля.

## Що всередині

- Каталог: категорії з підкатегоріями, розміри, кольори, залишки по варіантах товару, фільтри, пошук
- Картка товару: галерея, вибір розміру/кольору з урахуванням залишку, quick-add з каталогу
- Кошик (Zustand, persist у localStorage) і чекаут без обов'язкової реєстрації
- Адмінка: товари, категорії, замовлення, промокоди, завантаження фото (Supabase Storage)
- Кабінет клієнта: реєстрація/вхід (телефон+пароль або Google), історія замовлень, збережені адреси, накопичувальна знижка за рівнями
- Готові, але свідомо "заглушені" точки інтеграції: оплата, служба доставки, аналітика (див. `CLAUDE.md`)

## Швидкий старт

Повний покроковий чекліст для нового клієнта — у [`SETUP-CHECKLIST.md`](./SETUP-CHECKLIST.md). Коротко:

```bash
npm install
cp .env.example .env   # заповнити Supabase/NextAuth ключі
npm run prisma:migrate
npm run prisma:seed
npm run dev
```

## Документація

- [`CLAUDE.md`](./CLAUDE.md) — стек, структура папок, архітектурні рішення (для Claude Code і для себе через пів року)
